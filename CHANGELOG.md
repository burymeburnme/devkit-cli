# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-18

### Added
- Initial release of devkit-cli
- Multi-language scaffolding: Node.js, Python, Go
- 4 template types: basic, cli, api, lib
- CLI argument parsing with --help and --version
- Git initialization and dependency auto-install options
- 6 GitHub achievement unlocker scripts
- Interactive achievement menu (unlock-all.sh)
- Achievement progress tracker
- GitHub Actions CI/CD workflows
- Devcontainer config for GitHub Codespaces
- Issue and PR templates
- Full documentation and troubleshooting guide

### Scripts
- setup.sh — environment validation
- quickdraw.sh — ⚡ Quickdraw badge
- yolo.sh — 🤠 YOLO badge
- publicist.sh — 📢 Publicist badge
- pull-shark.sh — 🦈 Pull Shark (all tiers)
- pair-extraordinaire.sh — 🤝 Pair Extraordinaire badge
- unlock-all.sh — Interactive master menu
